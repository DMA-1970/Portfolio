Automated Multi-Cloud Compliance Assurance Framework

Research completed

My role: I conceived, designed and built AMCAF as my MSc capstone project, creating a provider-agnostic compliance framework for regulated financial services operating across AWS, Microsoft Azure and Google Cloud.

Impact: Demonstrated how automated technical checks can improve multi-cloud compliance visibility by mapping cloud evidence to regulatory and security control objectives across multiple jurisdictions.

Evidence: Developed a 20-control model and working Python prototype, validated with live scripted assessments against real AWS, Azure and GCP environments. Now registered internally at MillTech, where it is being trialled incrementally against production infrastructure.
